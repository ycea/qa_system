# Результаты задач и критерии оценки готовности

| ID      | Результат задачи                               | Критерии оценки готовности                                                                                                                                                                                                                                                                                                                                                                    |
| ------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AUTH-01 | Модуль создания пользователя                   | 1. Форма содержит поля: логин, email, пароль, подтверждение пароля.<br>2. При несовпадении паролей — сообщение об ошибке.<br>3. При занятом логине — сообщение об ошибке.<br>4. При некорректном email — сообщение об ошибке.<br>5. После успешной регистрации — переход на форму входа.                                                                                                      |
| AUTH-02 | Модуль авторизации пользователя                | 1. Форма содержит поля: логин и пароль.<br>2. При неверных данных — сообщение об ошибке.<br>3. При верных данных — переход на страницу со списком проектов.                                                                                                                                                                                                                                   |
| PROJ-01 | Модуль создания проекта                        | 1. Форма содержит поля: название (обязательное), описание.<br>2. При пустом названии — сообщение об ошибке.<br>3. После сохранения проект появился в списке проектов пользователя.<br>4. Создатель автоматически стал Администратором проекта.                                                                                                                                                |
| PROJ-02 | Модуль по работе со списком проектов           | 1. На главной странице отображаются только проекты, в которых состоит пользователь.<br>2. Каждый проект — кликабельная карточка.<br>3. На карточке указаны название и количество открытых багов.<br>4. По клику на карточку — переход на страницу проекта.                                                                                                                                    |
| PROJ-03 | Добавленный участник в проект                  | 1. На странице проекта есть поле ввода логина и выбор роли.<br>2. При вводе существующего логина пользователь добавляется в проект.<br>3. При вводе несуществующего логина — сообщение «Пользователь не найден».<br>4. Новый участник видит этот проект в своём списке.                                                                                                                       |
| PROJ-04 | Раздел для просмотра состава команды           | 1. На странице проекта отображается таблица всех участников.<br>2. У каждого участника указаны логин и роль.<br>3. Администратор видит кнопки управления рядом с каждым участником.                                                                                                                                                                                                           |
| PROJ-05 | Функционал по удалению пользователя из проекта | 1. Кнопка удаления доступна только Администратору проекта.<br>2. После подтверждения участник исчез из списка команды.<br>3. Удалённый участник больше не видит этот проект в своём списке.                                                                                                                                                                                                   |
| PROJ-06 | Модуль по управлению справочниками проекта     | 1. Раздел доступен только Администратору проекта.<br>2. Администратор может создать новый статус, приоритет или серьёзность.<br>3. Может отредактировать название существующего элемента.<br>4. Может удалить элемент справочника. Если на элемент используется, то необходимо убрать мешающие связи. Кнопка в таком случае не активна.<br>5. Разработчик и Тестировщик не видят этот раздел. |
